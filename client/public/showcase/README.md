# Showcase images

Add your own work/sector images here to replace the placeholders on the home page.

Suggested filenames (used in `Home.jsx` if you switch to local paths):

- `power.jpg` – Power & Utilities
- `solar.jpg` – Solar Projects
- `telecom.jpg` – Telecom
- `railways.jpg` – Railways
- `psu.jpg` – PSU & Government
- `consultancy.jpg` – Consultancy

Use 800×520 or similar aspect ratio for best display. Then in `client/src/pages/Home.jsx`, set each `showcaseItems` entry’s `image` to `'/showcase/your-filename.jpg'`.
