# Global assets (logos, images)

Place shared images here used across the marketing site.

## Hero carousel (Home page)

The hero carousel uses full-bleed background images. Add these files for best effect:

- **hero-2.jpg** – Second slide (e.g. enterprise / collections theme). Recommended: 1920×1080 or larger, landscape.
- **hero-3.jpg** – Third slide (e.g. sectors / PAN India theme). Recommended: 1920×1080 or larger, landscape.

The first slide uses `/hero.png` from the project root. If `hero-2.jpg` or `hero-3.jpg` are missing, the slide shows a solid blue fallback.

## Other assets

- **ntpc.png** – NTPC logo for the PSU & Government showcase card on the Home page.  
  If present, it is used; otherwise the app falls back to a public NTPC logo.  
  Recommended size: about 200–330px wide, transparent or white background.
